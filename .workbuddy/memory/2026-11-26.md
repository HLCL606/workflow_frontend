# 2026-11-26

## workflow_frontend：搭建 Next.js 登录/注册前台

- 技术栈：Next.js 16.4.6（App Router + Turbopack）+ Tailwind CSS 4 + shadcn/ui（新 CLI 的 `base-nova` 预设，底层是 Base UI，`cn` 来自 `cn` 包）。
- 脚手架：`create-next-app` 生成 src 目录项目，`npx shadcn@latest init -p nova`（新版 CLI 没有 `--base-color`，改为 `-p <preset>`），再 add button/input/label/card/field/checkbox/separator/alert/sonner。
- 字体：去掉 `next/font/google`（构建期要联网），改在 `globals.css` 的 `:root` 写系统字体栈 `--font-sans`，否则 `@theme inline` 里 `--font-sans: var(--font-sans)` 会指向空值。
- 请求层：`lib/http/client.ts` 单出口 fetch（baseURL、query、超时、Bearer、统一响应体解包、错误归一 ApiError、401 全局回调）；`lib/api/auth.ts` 定义 `AuthApi` 契约，`lib/api/mock/auth.ts` 提供假实现，`lib/api/index.ts` 按 `NEXT_PUBLIC_API_MODE` 选择，页面只 import `authApi`。
- 登录态：`lib/auth/token.ts`（记住我 → localStorage / sessionStorage）+ `lib/auth/context.tsx`（AuthProvider，启动时 `me()` 恢复）+ `components/auth/require-auth.tsx` 客户端守卫。
- 校验：零依赖手写 `lib/validators/auth.ts`。npm 装 react-hook-form/zod 时因清理 `node_modules/conf/node_modules/.ajv-*` 被沙箱拦截，遂放弃第三方表单库。
- 坑：模板默认开 `cacheComponents` + `partialPrefetching`，客户端守卫的 `/dashboard` 会持续报 `instant-navigation` 无法校验，且 `export const instant = false` 不能写在客户端组件里 → 在 `next.config.ts` 关掉这两项。
- 验证：`testdata/verify-auth-flow.mjs` 用 CDP 驱动无头 Chrome 跑 13 项流程检查，全通过；生产构建通过（需用 `distDir` 指到 `.next/verify*`，否则沙箱会拦 `.next` 清理）。`.next/verify`、`.next/verify2` 是遗留产物。
